# oil


# ⛽ ปั๊มน้ำมันหาดใหญ่

แอปพลิเคชันติดตามสถานะน้ำมันแบบเรียลไทม์ สำหรับชาวหาดใหญ่และสงขลา  
ขับเคลื่อนด้วยพลังชุมชน — ใครเจอปั๊มไหนมีหรือหมด ช่วยกันรายงานได้เลย

🔗 **ทดลองใช้งาน:** [naigolf.github.io/oil](https://naigolf.github.io/oil/)

---

## ✨ ฟีเจอร์หลัก

- 🗺️ แสดงรายชื่อสถานีบริการน้ำมันในหาดใหญ่ทั้งหมด
- 🟢 ตรวจสอบสถานะน้ำมันแบบเรียลไทม์ — มี / หมด
- ⛽ รองรับทุกประเภทน้ำมัน: ดีเซล, G95, G91, E20
- 🔍 ค้นหาและกรองตามแบรนด์หรือชนิดน้ำมัน
- 📍 นำทางไปยังปั๊มได้ทันทีผ่าน Google Maps
- 📞 แสดงเบอร์โทรศัพท์สถานีบริการ
- 👥 ระบบรายงานสถานะโดยชุมชน (Community Report)
- 📩 ฟอร์มติดต่อทีมงานพร้อมแนบรูปภาพ
